TURN DESIGN SYSTEM

TURN keeps its loud, tactile and friendly character. The system underneath now names the colours, shapes and interaction roles that make that character consistent.

Core interaction rule Forward is pink. Navigation is orange.

Utility actions stay quiet. Driving controls use literal, stable colours. Shape communicates interaction type, not decoration.

01 · Normative decisions

One clear path through every screen.

The visual hierarchy follows the order of interaction. Content selection comes first, quiet utilities remain adjacent, and the primary action completes the current step.

Primary action

Pink 500 + pill

INSTALL TURN, RACE THIS TRACK and RACE THIS CAR share the same colour and shape. Placement and wording provide the remaining context.

Utility action

Paper + pill

SETTINGS, HOW TO PLAY and GIVE FEEDBACK are visually equal and intentionally quieter than the selected-track action.

Navigation action

Orange 500

All Close, Back and Leave actions use orange. Circular X controls remain circles; textual navigation keeps its component-appropriate shape.

06 · Production adoption

The first two migration steps are now live.

The system is introduced without replacing existing selectors. The compatibility layer lets TURN consolidate gradually rather than through a risky visual rewrite.

  1. Shared token file introduced.design-tokens.css defines primitive colours, semantic roles, driving-control roles, geometry, spacing and elevation.
  2. Existing variables aliased.--ink, --paper, --cyan, --pink, --yellow, --lime and the M8 variables resolve through the new primitives.
  3. Semantic production layer applied.design-semantic.css assigns primary, utility, navigation and gameplay-control roles without changing component markup.
  4. Next migration step.Normalize individual component radii, border weights and shadow offsets one family at a time, with visual and real-device regression checks.

Normative principle: standardize the grammar underneath TURN, not the personality players already know. Saturated colour, black-ink construction, warm paper and tactile hard shadows remain the visual signature.
