02 · Colour system

Primitive values first. Meaning second.

Components use semantic variables. Semantic variables map to the primitive palette. Raw colours stay available for expressive track art, but reusable interface elements do not choose colours ad hoc.

05 · Adoption

The first two migration steps are live.

Shared tokens and compatibility aliases are in production. Native form controls and disclosures now join the normative system.

  1. Shared token file: complete. Primitive and semantic roles live in design-tokens.css.
  2. Compatibility aliases: complete. Existing variables resolve to normative primitives.
  3. Native components: active. Settings headings, radios, checkboxes, range input and disclosures use shared rules.
  4. Continue incrementally. Normalize geometry component family by component family.
