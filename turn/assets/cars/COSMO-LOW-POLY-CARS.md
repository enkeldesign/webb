# Cosmo Low Poly Cars

TURN's **Supercar** model is adapted from `ghini.glb` in **Low Poly Cars – By Cosmo**.

- Creator: Cosmo
- Pack: Low Poly Cars
- Source: https://cosmo-art.itch.io/low-poly-cars
- Original publication: 20 October 2024
- License for the free assets: CC0 1.0 Universal / public domain dedication

TURN modifies the source mesh hierarchy so the four wheels use TURN's generic front/back steering names and separate protected rim/tyre children. The source texture is embedded in the adapted model payload.
