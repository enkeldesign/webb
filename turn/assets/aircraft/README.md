# AMV Lab aircraft models

TURN Airport r53 loads logo-free aircraft models from the public [`amvlab/aircraft-models`](https://github.com/amvlab/aircraft-models) repository at commit `91d835e8e851b2317fe79af291c9fed6153fd525`.

Models used:

- `A320_nologo.glb`
- `B737_nologo.glb`
- `A380_nologo.glb`
- `B787_nologo.glb`

The source repository licenses its models and images under **Creative Commons Attribution 4.0 International (CC BY 4.0)**.

TURN does not redistribute modified model files in this repository. The GLB files are loaded from the pinned upstream commit and are scaled, oriented, outlined, and positioned at runtime.
